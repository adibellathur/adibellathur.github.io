# Adithya Bellathur - Portfolio Website

A modern, minimalist portfolio website built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Modern Stack**: Built with React 19, Vite, and TypeScript
- **Styling**: Tailwind CSS for utility-first styling
- **Typography**: Geist Mono font for a clean, monospace aesthetic
- **Responsive**: Mobile-first responsive design
- **Fast**: Optimized build with Vite for fast development and production builds

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This site is configured for GitHub Pages deployment. The built files in the `dist` directory can be deployed to any static hosting service.

## Project Structure

- `src/App.tsx` - Main application component
- `src/assets/` - Static assets including profile image
- `src/lib/utils.ts` - Utility functions for styling
- `tailwind.config.js` - Tailwind CSS configuration
- `vite.config.ts` - Vite configuration
